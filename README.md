## Project Overview
HealthFirst Pharmacy serves underserved communities in Cape Town by providing affordable medications and first aid services. Expanded to wellness consultations and chronic medication support. This website provides medication info, enables secure prescription refills, promotes health awareness via blog, and improves patient engagement. Part 1 was HTML structure, Part 2 is CSS responsive design, Part 3 will be JavaScript.

**Mission:** To make healthcare accessible and affordable for all.
**Vision:** To be the leading community pharmacy in Cape Town, trusted for care and reliability.
**Target Audience:** Local residents, families, elderly patients, chronic medication users.

## Website Goals & KPIs
**Goals:** Provide medication info, enable prescription refills, promote health awareness, improve patient engagement.
**KPIs:** Number of online refill requests, website traffic from health articles, patient satisfaction surveys, newsletter subscriptions.
